#  VisionGate: PDPM IIITDMJ Student Entry-Exit Management System

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Website-06b6d4?style=for-the-badge&logo=vercel)](https://vision-gate-sbta.vercel.app/)

A secure, digital platform designed to record, monitor, and manage student movement across the **PDPM IIITDMJ** campus. VisionGate provides real-time access for administration and guards, streamlining the gate-pass process and completely digitizing campus security.

> **🎓 Academic Project:** This application was developed as a collaborative group project for our college coursework.

## ✨ Key Features

* **Student Portal:** A dedicated dashboard for students to view their profile, room details, and current campus status.
* **Movement Logging:** Automated tracking of entry and exit times, including the specific purpose of the movement (e.g., Market, Tea Break).
* **Vacation Management:** A complete workflow for students to apply for extended leaves or vacations, complete with destination tracking, return dates, and approval status.
* **Real-Time Status Tracking:** Live status indicators (Inside/Outside Campus) and approval tracking for vacation requests (Pending, Approved, Rejected).
* **Role-Based Access:** Dedicated interfaces and real-time monitoring capabilities for students, campus administration, and security guards.
* **Responsive UI:** A sleek, dark-themed, and mobile-friendly interface built for modern browsers.

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, CSS (Custom Dark Theme)
* **Backend:** Python, FastAPI, Uvicorn
* **Deployment:** Vercel (Frontend)
